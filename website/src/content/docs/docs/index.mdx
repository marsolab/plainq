**PlainQ** is a small, self-contained message broker written in Go. A single
binary gives you reliable work queues, topic-based pub/sub, gRPC and HTTP APIs,
a CLI, a terminal UI, and the Houston admin dashboard — backed by SQLite,
Turso, or PostgreSQL.

<CardGrid stagger>
  <Card title="Queues + pub/sub" icon="rocket">
    Send work to competing consumers, or publish once to fan out into every
    subscribed queue.
  </Card>
  <Card title="One operational unit" icon="laptop">
    Run `./plainq serve` for the broker APIs, storage, metrics, and admin UI. No
    separate broker fleet.
  </Card>
  <Card title="Pick your storage" icon="seti:db">
    Embedded SQLite by default, Turso for hosted SQLite, or PostgreSQL for a
    shared backend.
  </Card>
  <Card title="Built for automation" icon="approve-check">
    Use typed gRPC and JSON-friendly CLI output for queues, plus HTTP for
    pub/sub and admin integrations.
  </Card>
</CardGrid>
